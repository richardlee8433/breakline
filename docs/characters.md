# Breakline — 人物設定
版本：v0.1  
更新日期：2026-10-03

本文件記錄四位主要角色的建議設定與立繪方向，供編劇、美術與後續開發參考。名字與背景為目前設計提案；尚未將遊戲中的暫定名字與對話替換為本文件版本。

## 文件與遊戲包的關係

本文件位於 `docs/characters.md`，屬於開發文件。不要移入 `public/`、不要由遊戲程式 import 或 fetch，也不要加入發佈素材清單。依目前 Vite 建置設定，這份文件不會進入 `dist/` 遊戲包。

## 整體角色方向

有本事、各有盲點、危急時仍能互相吐槽。故事圍繞一次突破封鎖與護送撤離的行動，保留輕鬆科幻冒險的語氣。

Helion 是能源企業與古文明探索力量。本作對抗其地方封鎖艦隊，不將整間公司與所有員工都設定成惡人。

四人對話分工：
- 凱問「現在怎麼辦」，並作出現場決定。
- 蘿莎解決「怎麼做到」，提供機械與戰術限制。
- 米拉發現「這代表什麼」，將異常轉為可用線索。
- 沃斯施加「你們還有多少時間」的壓力。

## 1. Kai Mercer｜凱・默瑟

**身份：** 地方貨運飛行員，撤離行動的護航駕駛。  
**一句話：** 嘴上說只是送貨，最後總會多管一件事。

### 個性與動機
隨和、反應快，用玩笑掩飾緊張；對答應的事很認真。熟悉舊航道、貨運船與不可靠的設備，靠經驗和臨場判斷生存。他並非傳奇王牌，最初只是想把研究隊送出去，後來承認自己無法接受有人把平民困住。

### 弱點與角色變化
習慣自己扛風險，不太會求援。故事中逐步學會相信蘿莎的備案、米拉的判斷，讓撤離成為團隊合作的成果。

### 台詞風格
生活化、自嘲、帶貨運工作的比喻。真正危險時句子變短，不在每次危機都硬講笑話。

台詞示例：「我的工作是把貨送到。今天的貨比較會尖叫。」

### 立繪方向
成年男性，約三十歲出頭；暖色中等膚色、凌亂深棕髮、棕眼、親切的半笑。舊棕色飛行外套、紅圍巾、補丁肩章、實用飛行背帶與通訊耳機。姿勢放鬆，一手觸碰耳機。應呈現可靠的普通人，而非華麗軍事英雄。

## 2. Rosa Vega｜蘿莎・維加

**身份：** 工程師，將古文明核心接上主角舊戰機的人。  
**一句話：** 會罵你亂來，也會替你準備第二條命。

### 個性與動機
務實、直率、愛拆東西。關心別人的方式是把機器修好，並提前準備備用零件。建議背景：曾替 Helion 外包維修，熟悉企業設備的標準與漏洞，因此能提出具體、可信的技術判斷。

### 弱點與角色變化
對自己做的機器太有信心，偶爾低估未知科技。她需要逐步承認核心不完全受她控制，同時仍然為自己的工程決策負責。

### 與凱的關係
合作多年的搭檔，具有工作上的默契，不預設戀愛關係。凱知道她一定留了備案，蘿莎知道他一定會用到。

### 台詞風格
短、直接、具體；嘴上責備，行動上支持。技術解說優先說明玩家此刻應做什麼，不念長篇規格。

台詞示例：「備用散熱器不是讓你再亂來一次的。……好吧，這次可以。」

### 立繪方向
成年女性，約三十歲出頭；古銅棕色膚色、短深棕／紫棕鮑伯髮、棕眼、挑眉與會心笑。青綠工作服、捲袖、額頭上的焊接護目鏡、臉頰油污、耳後筆與工具腰帶。手持小型診斷器，姿態穩健。與 Lastlight 的工程師角色使用不同髮型與輪廓，保留同畫風。

## 3. Dr. Mira Sen｜米拉・森博士

**身份：** 撤離船上的古文明科技研究員。  
**一句話：** 越不合常理，她越想弄懂。

### 個性與動機
沉著、好奇，有乾冷幽默。善於從異常裡找規律，提出假說，也願意承認錯誤。她不只解說世界觀，還能從守衛動作辨認出維修程序，幫助隊伍找到通道。

### 弱點與角色變化
一遇到重要發現，就很難停止觀察，偶爾讓隊友頭痛。涉及人的安全時，她能放下研究；故事應給她一次主動選擇保護同伴的機會。

### 台詞風格
精確但易懂，保留「可能」「還不能確定」等分寸。以冷靜語氣說出令人不安的發現，幽默來自觀察，而非神祕預言。

台詞示例：「好消息，它認得我們的核心。壞消息，它似乎認為我們需要維修。」

### 立繪方向
成熟女性，約四十歲後段；深棕膚色、銀色短髮、沉思的棕眼、淡淡的微笑。細框眼鏡或單眼紫色資料鏡片、靛色實用田野研究外套、低調紫色幾何滾邊。手持資料平板，腰間掛密封晶體樣本。呈現科學家與探索者，不做成魔法師。

## 4. Commander Adrian Voss｜艾德里安・沃斯指揮官

**身份：** Helion 地方封鎖艦隊指揮官。  
**一句話：** 相信封鎖是必要措施，也真心認為自己能控制後果。

### 個性與動機
克制、精準、重視秩序；說話客氣卻帶壓力。他將古文明裝置視為可能引發災難的能源技術，也相信 Helion 有資格接管。這份信念同時符合公司的利益，不代表他的手段正當。

### 弱點與角色變化
相信所有問題都能靠控制解決，難以接受失控。戰鬥失利時可以變得更急切，但不突然變成失去理智的反派。結尾停止追擊，可因為再追下去會犧牲船員，顯示他具有自己的底線。

### 台詞風格
簡短、程序化、帶期限與後果。威脅不靠吼叫，不反覆宣稱公司邪惡，也不靠長篇演說交代陰謀。

台詞示例：「你可以不相信公司。但你正在運送的東西，也不會因此變得安全。」

### 立繪方向
成熟男性，約五十歲出頭；淺膚色、整齊深髮與灰白鬢角、灰藍眼、沉著嚴肅表情。標準化珍珠白／冷灰制服、工業黃細節、高領、小型階級標示、簡潔企業徽記與深色手套。雙臂交叉，姿態自律。避免惡意獰笑、華麗王室披風與過度裝飾。

## 立繪共通規格

- 使用 Lastlight 原人物立繪的日系視覺小說畫風：細緻乾淨線稿、賽璐璐陰影、適量布料質感、暖色輪廓光、成熟而富表情的臉部。
- 科幻服裝具有實際用途、縫線、硬體與使用痕跡。
- 正式遊戲素材採獨立角色半身／腰上立繪，透明背景；角色的頭、髮、手臂不可意外裁切。
- 四人維持一致的構圖比例與光源，各自有清楚輪廓與服裝配色。
- 第一版四人合圖僅作外觀提案；獨立立繪、表情差分與遊戲接入另行安排。
- 本次只保存人物文字設定，不上傳合圖，也不修改遊戲包或現有角色程式。
